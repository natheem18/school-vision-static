# SchoolSpark Website

Create a modern, professional, responsive school website inspired by the uploaded reference image for the header/navigation design.

Project Requirements

Build the website as a static website with static routing only.

Do NOT use dynamic routing.

Do NOT create dynamic page routes such as /campus/:id or /result/:year.

Each page should have its own fixed/static route.

Use clean, reusable components for the Navbar, Footer, Hero sections, Cards, Buttons and Forms.

Make the website fully responsive for desktop, tablet and mobile.

Use a premium educational/institutional design.

Keep the code clean, organized and easy to maintain.

Static Routes

Create these fixed pages:

/ → Home

/about → About

/campus → Campus

/results → Results

/contact → Contact

/admission → Admission Form

Header / Navbar

Use the uploaded image as the visual reference for the header.

The navigation should visually resemble the uploaded reference:

Dark blue/navy background

Spacious horizontal navigation

Bright pink/magenta admission CTA button on the right

Clean modern typography

Professional school branding

Header should remain visually strong on desktop.

On mobile, convert the navigation into a clean hamburger menu.

Do not copy the logo or branding from the reference image. Use it only as a layout and styling reference.

Important Technical Requirements

Use React + TypeScript if that is the default Lovable stack.

Use reusable components.

Use static routes only.

No dynamic routing.

No database.

No authentication.

No admin dashboard.

No CMS.

No unnecessary backend.

No dynamic URL parameters.

All website content can initially use static placeholder data.

Make all text, images and contact details easy to replace later.

Ensure all navbar links correctly navigate to their corresponding static pages.

Final Goal

The final website should look like a premium modern school website, with the uploaded reference image used specifically as inspiration for the navbar/header structure and visual style.

The website should feel trustworthy, educational, modern, professional and suitable for a reputed school.

Build the complete frontend with all pages, static routing, responsive design, reusable components and polished UI.
